# Experimental Results Summary

## Representation Reorganization During Grokking-Like Behavioral Transition

---

## 1. Overview

This document summarizes the results of a minimal operational demonstration
investigating latent representation changes during a behavioral transition from
memorization-dominated performance to generalization-capable performance.

The experiment uses modular addition as a controlled synthetic task and evaluates
whether behaviorally distinct checkpoints correspond to measurable differences in
hidden-layer representations.

The demonstration consists of three complementary components:

1. Behavioral trajectory analysis during training.
2. Representation compatibility analysis between selected checkpoints.
3. Negative control under disrupted task structure.

The goal is not to establish a universal mechanism of grokking, but to provide a
reproducible experimental protocol for studying representation changes during
behavioral transitions.

---

# 2. Experimental Setup

## Task

The model is trained on modular addition:

\[
(a+b)\mod p
\]

with:
```
p = 97

```
The dataset is generated by exhaustive enumeration of all possible input pairs.

---

## Model

Architecture:
Multilayer Perceptron (MLP)

Configuration:

| Parameter | Value |
|---|---:|
| Hidden dimension | 128 |
| Optimizer | AdamW |
| Learning rate | 0.001 |
| Weight decay | 1.0 |
| Maximum epochs | 10000 |
| Random seed | 42 |

---

# 3. Behavioral Checkpoint Identification

Two hidden-layer representation checkpoints were extracted according to
predefined behavioral criteria.

The checkpoints are treated as representative observations of distinct
behavioral states rather than as exact boundaries between regimes.

---

## 3.1 Memorization Checkpoint

Selection criterion:

\[
Train\ Accuracy > 0.99
\]

and

\[
Test\ Accuracy < 0.20
\]

Observed checkpoint:

| Metric | Value |
|---|---:|
| Epoch | 800 |
| Train accuracy | 0.9996 |
| Test accuracy | 0.0035 |

Interpretation:

The model demonstrates near-perfect training-set fitting while lacking
generalization performance.

This checkpoint represents a memorization-dominated behavioral state.

---

## 3.2 Generalization Checkpoint

Selection criterion:

\[
Train\ Accuracy > 0.99
\]

and

\[
Test\ Accuracy > 0.95
\]

Observed checkpoint:

| Metric | Value |
|---|---:|
| Epoch | 7500 |
| Train accuracy | 1.0000 |
| Test accuracy | 0.9520 |

Interpretation:

The model reaches a behaviorally successful state with strong test performance.

This checkpoint represents a generalization-capable behavioral state.

---

# 4. Training Trajectory Analysis

The training trajectory demonstrates a temporal separation between fitting the
training data and achieving generalization performance.

Observed behavior:

- Training accuracy saturates early.
- Test accuracy improves substantially only after extended optimization.
- Loss trajectories show continued optimization after initial memorization.

The extracted checkpoints therefore correspond to distinct observations along
the same optimization trajectory.

---

# 5. Latent Representation Analysis

## Metric

Hidden-layer representations were compared using linear Centered Kernel
Alignment (CKA).

The metric is used as a representation compatibility observable:

\[
CKA(H_1,H_2)
\]

where:

- \(H_1\) and \(H_2\) denote hidden-layer activation matrices;
- higher values indicate stronger representation compatibility.

---

## 5.1 Memorization vs Generalization Representation Comparison

Comparison:

\[
H_{mem}
\quad\text{vs}\quad
H_{gen}
\]

Result:

| Comparison | CKA |
|---|---:|
| Memorization checkpoint → Generalization checkpoint | 0.4050 |

Interpretation:

The hidden representations at the two behavioral checkpoints exhibit limited
compatibility.

This observation is consistent with a representation reorganization occurring
during the behavioral transition.

---

# 6. Negative Control Experiment

## Control Design

The same model architecture and training pipeline were applied after disrupting
the task structure.

The correct modular addition labels were replaced with random labels.

The purpose of this control was to test whether the observed representation
marker depends on the underlying task structure rather than generic optimization.

---

## Negative Control Result

Comparison:

\[
H_{noise}
\quad\text{vs}\quad
H_{gen}
\]

Result:

| Comparison | CKA |
|---|---:|
| Noise model → Generalization reference | 0.0168 |

Decision criterion:

\[
CKA < 0.85
\]

Outcome:
NEGATIVE TEST PASSED

Interpretation:

The representation compatibility marker observed in the structured task is not
preserved after task structure disruption.

---

# 7. Combined Experimental Interpretation

The demonstration provides three aligned observations:

## Behavioral level

The model transitions from:

\[
\text{memorization-dominated performance}
\]

to:

\[
\text{generalization-capable performance}
\]

during training.

---

## Representation level

The transition is accompanied by measurable changes in hidden-layer
representation compatibility:

\[
CKA(H_{mem},H_{gen})=0.405
\]

---

## Control level

The corresponding representation compatibility is absent when the task structure
is disrupted:

\[
CKA(H_{noise},H_{gen})=0.0168
\]

---

Together, these results support the following operational interpretation:

\[
\boxed{
\text{behavioral transition}
\rightarrow
\text{latent representation reorganization}
}
\]

---

# 8. Scope and Limitations

This experiment is a controlled demonstration and should not be interpreted as
a universal explanation of grokking phenomena.

The results do not establish:

- a universal mechanism of neural phase transitions;
- a mathematical invariant;
- causal necessity of representation changes.

The current evidence is limited to:

- one synthetic task;
- one model architecture;
- one training configuration;
- one random seed.

---

# 9. Future Validation Directions

Potential extensions include:

- multiple random seeds;
- alternative architectures;
- additional algorithmic tasks;
- trajectory-level representation analysis;
- comparison with alternative representation similarity measures.
